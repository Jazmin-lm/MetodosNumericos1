ANÁLISIS NUMÉRICO

Búsqueda de raíces

Estimación del tiempo necesario para alcanzar el umbral de deterioro de un componente mecánico.

Modelo de predicción

El sistema utiliza las mediciones históricas del componente para construir automáticamente un modelo cuadrático mediante mínimos cuadrados. Posteriormente, aplica los métodos de Bisección, Newton-Raphson y Secante para estimar cuándo se alcanzará el umbral de inspección.

D(t) = D₀ + αt + βt²

MÉTODOS NUMÉRICOS

Integración del deterioro

Estima la magnitud acumulada del deterioro a partir de las mediciones históricas de un componente.

¿Qué calcula esta sección?

Se aplica el método del trapecio compuesto sobre los datos registrados. Cada intervalo utiliza sus tiempos reales, por lo que también se admiten mediciones con separación no uniforme. El resultado representa el área bajo la curva de deterioro, no el porcentaje actual ni el tiempo de mantenimiento.

I ≈ Σ [(D(tᵢ) + D(tᵢ₊₁)) / 2] · (tᵢ₊₁ − tᵢ)

Se reutiliza el modelo cuadrático construido con las mediciones históricas. La búsqueda de raíces estima el tiempo en que el deterioro alcanza el umbral definido para el componente. La intervención posterior es una simulación hipotética y no representa una reparación real.
